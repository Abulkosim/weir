# v0.3.0

2026-10-25 · [Download](https://github.com/Abulkosim/weir/releases/tag/v0.3.0)

- Right-click the tray icon to run a speed test or check the connection without opening the popover, or to jump to History and Settings.
- Hover the tray icon to see the last download, upload and latency and when the test ran.
- Keyboard: ⌘T (Ctrl+T on Windows) runs a test and ⌘K (Ctrl+K) checks the connection. Buttons show their shortcut on hover.
- Copy summary, at the end of the result details, puts the server, time, speeds, latency and verdict on the clipboard as plain text.
- The tray icon is redrawn only when it changes, so a test uses less CPU.

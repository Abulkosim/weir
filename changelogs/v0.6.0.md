# v0.6.0

2026-10-29 · [Download](https://github.com/Abulkosim/weir/releases/tag/v0.6.0)

- Read Weir's results from scripts: `weir --json` prints the last test, `weir history` every test and outage, and `weir test` runs a full test and prints it. See README → Command line.
- `weir test` refuses a hotspot or metered connection unless you add `--allow-metered`, and never adds its result to History.
- With Homebrew, the `weir` command is on your `PATH` once Weir has opened.
